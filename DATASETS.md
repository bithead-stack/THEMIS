# Datasets

This project supports six network-security datasets.

## Included Datasets

The following datasets are included in the `dataset/` directory and are tracked with Git LFS:

| Dataset | Repository path |
| --- | --- |
| BAI-Net26 | `dataset/BAI-Net26.csv` |
| ZAPT | `dataset/ZAPT.csv` |

## External Datasets

The remaining datasets can be obtained from their respective project or distribution pages:

| Dataset | Source |
| --- | --- |
| DAPT2020 | [Kaggle](https://www.kaggle.com/datasets/sowmyamyneni/dapt2020) |
| EarlyCrow | [GitHub](https://github.com/ICL-ml4csec/EarlyCrowAPT/tree/main/data) |
| Unraveled | [GitLab](https://gitlab.com/asu22/unraveled) |
| UNSW-NB15-2024 | [UNSW Research](https://research.unsw.edu.au/projects/unsw-nb15-dataset) |

Please review the terms and licenses published by each dataset provider before downloading, using, or redistributing the data.
